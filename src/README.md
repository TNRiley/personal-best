# Personal Best — build pipeline

```bash
python fetch.py            # WCA export → ../.cache/ (~380 MB zip, ~1.6 GB unpacked)
python build_payload.py    # → payload.json (~20 KB); needs pandas; takes a few minutes
python inject.py           # template.html + payload.json → ../index.html, wrapped and linked
```

`inject.py --no-finish` leaves an Artifact-style fragment (no doctype, no catalog breadcrumb).
`payload.json` and `.cache/` are gitignored; both are regenerated by the first two steps.
See `../REBUILD.md` for the definitions, the traps, and the numbers a rebuild should reproduce.
